# Optimizer-W11
Optimizer W11 is a performance tuning tool for Windows 11 that automates system tweaks, gaming enhancements, and privacy settings. It features a minimal GUI with real-time progress tracking, modifies power schemes, services, and network configurations, while disabling telemetry and unnecessary apps. Perfect for gamers and power users seeking maximum performance and privacy.

## 📌 Requirements
*   Windows 11
*   Administrator privileges

## ▶️ Usage
1.  Download the [latest available release](https://github.com/Simv135/Optimizer-W11/releases).
2.  Click "Optimize" to start the process.
3.  Wait for completion - the progress bar will show the current status.
4.  Restart the system after completion to apply all changes.

## 🚀 Features
**Implemented Optimizations**
*   **Create Restore Point** - Creates automatic system restore point
*   **System Cleanup & Backup** - Cleans temp files, update cache, prefetch, backup
*   **Performance & Power Tweaks** - Power optimizations, NTFS tweaks, system timers
*   **Gaming & Multimedia Optimizations** - Gaming priority, DirectX tweaks, MMCSS configuration
*   **Privacy & Telemetry Configuration** - Disables telemetry, browser metrics, suggestions
*   **Windows Experience & UI Tweaks** - Interface optimizations, notifications, synchronization
*   **Network & Hardware Optimization** - TCP/IP tuning, USB optimizations, mouse/keyboard
*   **Unnecessary Components Removal** - Removes preinstalled apps, Game Bar, Cortana
*   **System Services Configuration** - Configures Windows services (DiagTrack, Xbox, BITS, etc.)

## ⚠️ Warnings
*   **Restart:** Some changes require a system restart to take effect.
*   **Customization:** The optimizations might disable features that some users prefer to keep enabled.
